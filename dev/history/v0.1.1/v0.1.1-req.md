## 実装済

[実装計画・報告](v0.1.1-imp.md)に検証範囲を記録。P1は自動回帰済み、最終GUI確認はP3で実施する。

- [x] R1: 独立プレビューのチェックを入れたりしないと、アプリを選んだだけではプレビューされないのが不自然。アプリの選択を変えたらプレビューでいいと思います。
- [x] R2: ただし、独立プレビューが本ツールの設定画面より手前に出るのは操作がロックされ問題となるため、本ツールを常時最前面にするとか、前後関係を維持するとかが必要かと思います。
- [x] R3: Unity Capture未導入環境に向けたインストールガイド表示またはワンクリックインストーラがほしいです。
- [x] R4: 保存完了メッセージの右にフォルダを開くボタンがあるとうれしい。
- [x] R5: 動画再生のショートカットキーは、YouTubeのコントローラと同じようなキーを割り当てる。
- [x] R6: 複数同時再生の「すべて再生」は、先頭からという意味ではなく、現在見ている位置からスタートしてほしい。開始位置をずらしたい場面もあるため。「先頭へ」があるので問題はない。

## 実装上の扱い

ユーザーが挙げた選択肢の範囲内で、R3はアプリ内の導入ガイドを採用する。公式ページへの導線と導入後の再確認を用意する。

R5は単体・複数の両方を内蔵プレイヤーで操作する。Space/K、J/L、左右矢印、Home/End、0～9、一時停止中のカンマ/ピリオド、F/Escとキー案内を用意する。音声のない既存プレイヤーの範囲で対応する。

R6は各動画に設定した秒位置の差を保って再生する。「先頭へ」と全体シークは明示的に位置をそろえる操作として残す。
