# 使い方

1. 「設定」で保存先とFFmpegを指定する。既定の保存先は利用者の「ビデオ」内のCapchunScreen。
2. ウィンドウまたはモニターを選ぶ。対象が見つからなければ検索を消して「対象を更新」を押す。
3. 対象を選ぶと自動でプレビューが始まる。検索・対象種類・WGC設定の変更後も最新対象の映像を表示する。「プレビュー停止」で止めた後も、対象を選び直すと再開する。独立プレビューのチェックは不要。
4. FPS、画質、MP4/MKV、開始までの秒数と最長秒数を決める。最長0は時間制限なし。
5. 「録画開始」を押す。カウントダウン中は同じボタンで中止できる。
6. 「録画停止」またはCtrl+Shift+F9で止める。「保存完了」の表示を待つ。メッセージ右の「保存先を開く」で、最後に正常保存した動画のフォルダーを開く。録画中にアプリを閉じた場合も保存してから終了する。
7. 「録画ファイル」タブで選択し、再生・TSV表示・名前変更・ごみ箱移動を行う。

## 取得方式

「選択ウィンドウのみ（WGC）」は、他窓が重なっても選択対象の映像を取得する。最小化・対象終了・キャプチャ失敗はエラーになる。保護された映像は取得できず、空白やエラーになる場合がある。画面全体へ自動的に切り替わらない。対象自身と別のポップアップ・メニューは含まれないことがある。

WGCを外したウィンドウ録画は画面上の位置を追従し、その場所に重なる他窓も映る。モニター録画は選択画面の全体を映す。録画開始後は出力寸法が固定され、対象のサイズ変更時には縦横比を維持した黒い余白が入る。

## 独立プレビューと仮想カメラ

「独立プレビュー」を有効にすると、同じ取得映像を最前面の枠なし窓へ表示する。左ドラッグで移動し、Escまたは右クリックの「閉じる」で閉じる。原寸表示を基本とし、画面より大きい映像だけ縮小する。閉じても本体の録画は停止しない。取得停止時は独立窓も待機表示に戻る。

独立窓を表示する間は本体も最前面になり、本体を選択すると独立窓より上へ出る。設定・導入ガイド・ファイル選択などのダイアログを開く間は独立窓を隠し、閉じると戻す。独立窓を閉じたら本体の最前面設定も元に戻る。

「仮想カメラ開始」で導入済みのUnity Captureへ配信する。受信アプリでUnity Video Captureを選択する。接続待ち・映像待機・配信中を区別し、停止時はNo Signalを送る。未導入の場合は理由と導入ガイドを表示する。「導入ガイド」からも、公式配布先・導入と解除の手順・導入状態の再確認を利用できる。詳細は[仮想カメラの利用条件と導入手順](virtual-camera.md)を参照。

## 複数動画の同時再生

録画一覧でCtrlを押しながら複数選択し「複数再生…」を押す。複数選択していない場合はファイル選択画面が開く。最大16本まで、別窓のグリッドに表示する。

「すべて再生」は各動画の現在位置から再開する。例として一方を10秒、もう一方を30秒に合わせてから押すと、20秒の差を保って再生する。終端に達した動画は「すべて再生」を押しても先頭へ戻らない。「一時停止」は各動画の位置で止める。

「先頭へ」と上部スライダーは明示的に位置をそろえる。全体シークは最長動画の秒位置を基準とし、短い動画は最終画像で止まる。上部の時刻は各動画の位置のうち最も先の秒位置を示す。各枠のボタンとスライダーは個別操作で、全体再生中に個別操作をすると全体を一時停止してから操作する。表示負荷を抑えるため各動画のプレビューは最大640×360、30fps。音声・入力演出は表示しない。元動画は変更しない。

録画一覧の「再生」とダブルクリックは、同じ内蔵プレイヤーを1本表示で開く。

## 動画再生のキー操作

[YouTubeの公式キー一覧](https://support.google.com/youtube/answer/7631406?hl=ja)に合わせた操作。上部の操作欄をクリックすると全体、動画の映像・操作欄をクリックするとその動画へ適用する。「キー操作…」またはF1／?で案内を開く。

|キー|操作|
|---|---|
|Space / K / メディア再生キー|再生・一時停止|
|J / L|10秒戻る・進む|
|← / →|5秒戻る・進む|
|Home / End|先頭・最後|
|0～9（テンキーも対応）|0～90%の位置へ移動|
|, / .|一時停止中に前・次の表示フレーム（30fps）|
|< / >（Shift + , / .）|再生速度を0.25倍ずつ変更（0.25～2倍）|
|F / Esc|全画面切替／全画面から元へ戻る|

全体に対するJ/L・左右の相対移動も、動画間の位置差を保つ（先頭・終端ではその動画だけ止まる）。全体への数字・Home/Endは同じ秒位置へそろえる。音声・字幕など、元のプレイヤーにない機能のキーは割り当てていない。

## 操作履歴

「操作履歴をTSVへ保存」を有効にすると、動画と同じ名前のTSVを保存する。入力は録画処理中だけ監視し、画像には焼き込まない。内蔵プレイヤーによる再生でも操作演出は表示しない。

単独の文字・数字は既定で除外する。「設定」で追加できる。ウィンドウ録画は対象またはその所有窓の操作だけ、モニター録画のキーボードはその画面内を中心とする前面窓だけを記録する。クリックの範囲判定は録画領域に従う。Ctrl+Shift+F9自身は履歴から除く。

TSVはUTF-8、6列（timestamp、frame、x、y、click、keys）。入力なしは`None`、領域外座標は`-1`。クリック名は`L-Click`、キーは`Ctrl,C`等。短い操作も次の取得フレームまで蓄積する。

## 保存とエラー

動画・TSVが確定するまで録画一覧へ表示しない。失敗した場合はエラー表示になり、完成品として扱わない。電源断・強制終了時の一時ファイル回復は保証しない。

改名時には同名TSVも処理し、既存ファイルへ上書きしない。ごみ箱移動が途中で失敗した場合は、移動済みと残ったファイルを通知する。TSVと動画の両方を元に戻すときは、ごみ箱から対応する2ファイルを復元する。

設定は`%LOCALAPPDATA%\CapchunScreen\settings.json`。破損した設定は読み込み時に上書きせず、次の保存時にバックアップしてから更新する。元のChulipVideo_config.jsonを移行・上書きしない。
