# インストールと削除

Windows 11 x64向けの未署名開発版です。[CapchunWindow Releases](https://github.com/KotorinChunChun/CapchunWindow/releases)の`CapchunWindow-0.1.2-setup.exe`を使用します。.NET Desktop Runtimeは同梱しています。KotorinToys 0.1.2以降からも公開版を照合して導入・更新・削除できます。

利用者単位へ導入し、スタートメニューに登録します。更新時は製品識別と正常停止を確認し、録画・処理中に終了を拒否した場合は中止します。設定・録画・TSVはインストール／削除時も保持します。削除はWindowsの「インストールされているアプリ」またはKotorinToysから行います。設定・保存先は[使い方](users-guide.md)を参照してください。

FFmpegとUnity Captureドライバーは同梱・自動導入しません。録画・再生には別途FFmpegを用意して設定画面で指定します。仮想カメラだけ別途Unity Captureの導入が必要です。SSCapture専用のFFmpeg導入操作は本製品の設定を変更しません。

入力記録はpassword欄や画面の機密情報を保護する保証ではありません。通常文字記録を有効にすると機密キーが保存される可能性があります。機密入力を含む録画・操作記録には使用しないでください。署名済み・すべての実機受入完了とは扱いません。
